# 도형의 방정식 자습

고등 수학(상) **Ⅰ. 도형의 방정식** 을 혼자 공부할 수 있게 만든 학습도구입니다.
기초학력(키다리) 자습 학습지 01~08차시의 내용과 수준을 그대로 따랐습니다.

- 공개 주소 : https://hongyul67-cpu.github.io/math-dohyeong-master/
- 파일 : `index.html` 하나뿐입니다. 열면 바로 돌아갑니다.

## 무엇이 들어 있나

| 화면 | 하는 일 |
|---|---|
| 📖 배우기 | 주제 10개의 공식·그림·주의점, 그리고 **풀이가 전부 보이는 예제** |
| ✏️ 연습 | 주제별 8문항. 한 문제마다 바로 채점 + 자세한 풀이 |
| 🏁 종합시험 | 20문항. 푸는 동안 정답·점수를 감춤 → 끝나면 오답노트 + 결과 제출 |
| 📕 오답노트 | 틀린 문제가 풀이와 함께 쌓입니다 (이 기기에만 저장) |

주제 (자습 학습지 차시와 짝)

1. 선분의 중점 · 2. 삼각형의 무게중심 · 3. 선분의 내분점 (01~02차시)
4. 두 점 사이의 거리 · 5. 직선의 방정식 · 6. 두 직선의 평행과 수직 (03~04차시)
7. 점과 직선 사이의 거리 · 8. 원의 방정식(표준형) (05~06차시)
9. 일반형 → 중심·반지름·넓이 · 10. 원이 될 조건 · 넓이의 최댓값 (07~08차시)

**문제는 풀 때마다 숫자가 바뀝니다.** 문제은행에서 뽑는 방식이 아니라,
주제마다 「문제 생성기」가 있어서 매번 새 숫자로 문제를 만들고 그에 맞는 풀이를 함께 만듭니다.
같은 학생이 몇 번을 풀어도 답을 외워서 맞힐 수 없습니다.

## 문제를 더 넣는 법

`index.html` 안에서 **`▼▼▼ 문제를 더 넣을 곳은 여기부터입니다 ▼▼▼`** 를 찾으세요.
고칠 곳은 두 군데뿐입니다.

### ① 이미 있는 주제에 문제 유형 하나 더 넣기

생성기 함수를 하나 쓰고, 그 주제의 `gens` 배열에 이름을 적어 주면 끝입니다.

```js
function g_mid3(){
  const x1 = R(-8,8), y1 = R(-8,8);          // R(a,b) = a 이상 b 이하 정수
  ...                                         // RZ(a,b) 는 0 을 빼고 뽑습니다
  return {
    tag   : '오답노트에 남길 짧은 이름',
    q     : '발문 (HTML 로 씁니다. 좌표는 P(x,y) 로)',
    fig   : planeOf([[x1,y1]], [{t:'pt',x:x1,y:y1,label:'A'}]),   // 문제에 보여 줄 그림
    solFig: '',                                // 정답이 보이는 그림은 반드시 여기에
    hint  : '공식만. 숫자를 대입한 결과는 절대 넣지 말 것',
    fields: [{label:'무엇을 적는 칸인지', ans:['정답','다른 표기도 허용']}],
    sol   : ['풀이 1단계', '2단계', '3단계']
  };
}
```

그리고 `TOPICS` 안의 해당 주제에서

```js
gens:[g_mid1, g_mid2, g_mid3],    // ← 여기에 추가
```

### ② 주제를 통째로 새로 넣기

`TOPICS` 배열에 한 칸 더 씁니다. 그러면 배우기·연습·종합시험에 저절로 들어갑니다.

```js
{ id:'tangent', unit:3, unitName:'Ⅰ-3 원의 방정식', name:'원과 직선의 위치 관계',
  pages:'자습 09차시', desc:'d 와 r 을 비교', gens:[g_tan1],
  concept:`여기에 개념 설명 HTML` },
```

`unit` 은 1·2·3 중 하나입니다(딱지 색이 달라집니다).

### 쓸 수 있는 도우미

| 함수 | 하는 일 |
|---|---|
| `R(a,b)` / `RZ(a,b)` | a~b 정수 뽑기 / 0 빼고 뽑기 |
| `pick([...])` | 목록에서 하나 뽑기 |
| `P(x,y)` | `(3, −5)` 처럼 좌표 쓰기 |
| `X` `Y` | 기울여 쓴 *x*, *y* |
| `frh(p,q)` / `frs(p,q)` | 분수 — 화면용 / 정답 비교용 문자열 |
| `sqh(안쪽)` | 제곱근 기호 (위에 줄이 그어집니다) |
| `lineMN(m,n)` / `lineGen(a,b,c)` | `y = 2x − 3` / `3x − 4y + 2 = 0` |
| `stdEq(a,b,r2)` / `genEq(D,E,F)` | 원의 표준형 / 일반형 |
| `planeOf(점들, 그릴것들)` | 좌표평면 그림 (범위를 알아서 잡아 줍니다) |

`planeOf` 에 넣는 그릴 것들 :
`{t:'pt',x,y,label}` 점 · `{t:'seg',x1,y1,x2,y2}` 선분 ·
`{t:'line',a,b,c}` 직선 *ax+by+c=0* · `{t:'circle',cx,cy,r}` 원

### 답 비교 규칙

`ans` 에 적은 글자와 학생이 쓴 글자를 **수로 바꿔서** 비교합니다.
`3/2` 와 `1.5` 는 같은 답으로 봅니다. 괄호·공백·− 기호는 알아서 걸러집니다.
수로 바꿀 수 없는 답(부등호 `>` 같은 것)은 글자 그대로 비교합니다.

## 고친 뒤 꼭 할 것

1. **문법 검사**
   ```bash
   node --check _chk.js
   ```
   (`index.html` 의 `<script>` 안쪽만 빼내어 검사 — 규약 5)

2. **문제가 실제로 맞는지 검사** — 브라우저 콘솔에서 생성기를 수백 번 돌려
   *답이 조건을 만족하는지* 를 다시 계산해 봅니다. 공식이 아니라 **다른 방법으로**
   확인해야 의미가 있습니다. (예: 내분점이면 벡터로 비율을 재계산)

3. **정답 유출 3원칙** — 힌트에 정답 금지 · 채점은 1회 · 발문은 한 값만 가리키기.
   정답이 보이는 그림은 `fig` 가 아니라 `solFig` 에 넣습니다.
